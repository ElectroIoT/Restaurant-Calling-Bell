# Restaurant Calling Bell (SI24R1)

Open-source wireless table-calling system: 10 coin-cell table remotes and one counter receiver
(OLED + DFPlayer Mini voice), ATmega328P + SI24R1 2.4 GHz.

Status: **work in progress** - see the sections below as they are filled in.
The earlier ATtiny85/STM32 concept is kept in `docs/archive-v0-attiny-stm32/`.
Vendor datasheets are in `docs/datasheets/`.
